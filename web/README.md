# 🌐 Blood Hero - Web Browser Version

โฟลเดอร์สำหรับเวอร์ชันเว็บเบราว์เซอร์ สามารถนำไฟล์ในโฟลเดอร์นี้ทั้งหมดไปอัปโหลดขึ้นเว็บโฮสติ้ง (เช่น GitHub Pages, Vercel, Netlify, itch.io, Firebase Hosting ฯลฯ) ได้ทันที

---

## 📂 รายการไฟล์ในโฟลเดอร์ `web/`

- **`index.html`**: ไฟล์หลักที่ใช้รันเกมบนเบราว์เซอร์
- **`vampire_warrior_blood_hero.html`**: ไฟล์เกมต้นฉบับ
- **`manifest.json`**: ไฟล์คอนฟิก PWA ให้ผู้เล่นกด "Add to Home Screen" หรือ "Install App" ได้จากเบราว์เซอร์
- **`sw.js`**: Service Worker สำหรับแคชไฟล์ให้สามารถเปิดเล่นแบบ Offline ได้
- **`hero_sprites.js`**: ข้อมูลสไปรต์ตัวละคร
- **`sprite-animation-128x128-frames/`**: โฟลเดอร์รูปภาพแอนิเมชันของตัวละคร
- **`run_web.ps1`**: สคริปต์เปิดเซิร์ฟเวอร์จำลองในเครื่องและเปิดเว็บเบราว์เซอร์ให้อัตโนมัติ

---

## 🎮 การควบคุมบนคอมพิวเตอร์ (PC / Mac)

| ปุ่ม | คำสั่ง |
| :--- | :--- |
| **W A S D** หรือ **ลูกศร** | เดิน / เคลื่อนที่ |
| **SPACEBAR** | แดช (Dash อมตะ 0.5 วินาที) |
| **เมาส์ (Mouse Move)** | หันหน้า / เล็งทิศทาง |
| **คลิกซ้าย (Mouse Left Click)** | ยิงโจมตีต่อเนื่อง |
| **P** หรือ **ESC** | เปิดเมนู Option / หยุดเกม / เซฟเกม |
| **F** หรือ **F11** | สลับโหมดเต็มจอ (Fullscreen) |
| **1, 2, 3** | เลือกการ์ด Perk เมื่อผ่านด่าน |
